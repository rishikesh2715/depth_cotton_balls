# Cotton Boll Sizing from RGB-D Video

Measure cotton boll dimensions (height/width in cm) from handheld Intel
RealSense RGB-D recordings, validated against caliper ground truth.

The project has two tracks that share the same data:

1. **SAM 2 measurement pipeline** (`pipeline/`) — interactive: click each
   boll once, SAM 2 propagates masks through the video, depth + intrinsics
   convert pixels to centimeters. Used to produce the first validated
   measurements and to bootstrap annotations.
2. **Supervised YOLOv11 track** (`annotation/`) — train seg + pose + an
   auxiliary occlusion head so detection/measurement runs without human
   clicks. Dataset iterations v1 (pilot) → v3 → v4 are documented in
   runbooks.

## Repository layout

| Path | What it is | In git? |
|---|---|---|
| `capture/` | RealSense recording + analysis scripts (`record_rgbd.py`, `analyze_rgbd.py`) | yes |
| `pipeline/` | 5-stage SAM 2 measurement pipeline (has its own README) | yes |
| `annotation/` | Annotation guidelines, CVAT label specs, dataset-conversion + training scripts, runbooks | yes |
| `docs/` | Planning docs and progress slide deck | yes |
| `models/` | Trained weights (`segment/`, `pose/`, `auxliary/`) + pretrained YOLO checkpoints | README only |
| `bags/` | Raw RealSense `.bag` recordings | README only |
| `work/` | Per-recording SAM 2 pipeline outputs (frames, depth, masks, measurements) | README only |
| `new_dataset/`, `combined_all_sequential*/` | Annotated COCO datasets received from annotators (v3, v4) | no |
| `annotation/datasets/` | YOLO-format datasets generated by the conversion scripts | no |
| `runs/` | Ultralytics training/val outputs | no |
| `_full_inference*/`, `interactive_viewer/` | Full-video inference dumps + HTML viewer | no |
| `videos/` | Raw MP4 recordings | no |
| `sam2/` | Vendored clone of [facebookresearch/sam2](https://github.com/facebookresearch/sam2) | no — clone it yourself |
| `_archive/` | Local scratch / superseded zips | no |

Folders marked "no" / "README only" hold large data that is regenerable or
distributed separately; `.gitignore` documents the policy inline.

## Quick start

```bash
pip install pyrealsense2 opencv-python numpy ultralytics
```

**Record:** `python capture/record_rgbd.py --width 1280 --height 720 --fps 30`
→ writes a `.bag` into the working directory (move it to `bags/`).

**Measure with SAM 2:** follow `pipeline/README.md`. Requires the `sam2/`
clone and its checkpoint (see that README). Outputs land in `work/<name>/`.

**Train YOLO models:** follow the runbooks in `annotation/` —
`RUNBOOK.md` (v1 pilot, CVAT setup), `V3_RUNBOOK.md`, `V4_RUNBOOK.md`
(current). Conversion scripts in `annotation/scripts/` turn the COCO
exports into YOLO seg/pose datasets; `train_v4_*.py` are the current
training entrypoints.

**Inspect predictions:** open `annotation/Inference_Viewer.html` in a
browser and point it at a folder of frame JPEG + JSON pairs
(`annotation/viewer_demo/` is a small committed example).
`annotation/Inference_Visualization_Legend.md` explains the overlay.

## Status (June 2026)

- SAM 2 pipeline validated against caliper ground truth on two handheld
  recordings (`docs/Cotton_Boll_Sizing_Progress.pptx` has the numbers).
- v4 dataset: 734 annotated instances across two camera angles with a
  sequential train/val split; seg + pose + aux models trained
  (`models/`), full-video inference reviewed in the HTML viewer.
- Next: RGB-D measurement-validity weighting and multi-frame aggregation
  (see `docs/Loss_and_RGBD_Plan_v0.pdf`).
